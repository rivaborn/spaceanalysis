# CLI (settings/control) + live telemetry for analyze-disk.ps1

Task: Lets add 1) a CLI so another process (e.g. this model) can modify how it runs and 2) Telemetry so another process (e/g/ this model) can see what the script is diong even if it is busy processign a lot of folders.

- [ ] Step 1: Add runtime-config + telemetry/control plumbing to analyze-disk.ps1. New params: -Settings <json> (load a run config file that another process writes), -StatusFile <json> (default 'status.json'), -ControlFile <json> (default 'control.json'), -Telemetry <switch>. Add functions: Load-Settings (merge a settings JSON of {root,top,depth,output,jsonReport} with CLI params, CLI wins), Write-Status (atomically write JSON {pid,startTime,timestamp,phase,current,itemsDone,itemsTotal,bytesCounted,filesCounted,elapsedSeconds,message} to StatusFile via tmp+Move-Item so a poller always sees a complete file; no-op unless -Telemetry), and Read-Control (parse ControlFile JSON and honor action=stop (set a global stop flag), pause (wait until resume/stop), and depth/top overrides; no-op and never errors when file missing unless -Telemetry). Instrument the top-level ranking loop to Write-Status (phase='top-scan', per-directory current/done/total) and call Read-Control at each directory boundary and after the phase.
